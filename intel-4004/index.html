Assembly quick reference

Numbers are decimal, 0xFF hex, or 0b1010 binary. Registers: R0–R15. Pairs: P0–P7. Labels end in :. Use .ORG address and .BYTE value, value for ROM data. Semicolons begin source annotations.

JCN condition bits: 1 = TEST low, 2 = carry set, 4 = A zero. Combine with OR; bit 8 inverts the result. Local branches must address the page of the PC after the instruction.

A label named DONE gets a debugger breakpoint automatically. There is no HALT instruction. Infinite loops are normal.

Model & limitations

Instruction-level emulation, not a transistor or bus-phase simulation. Instructions cost 8 or 16 clock periods; FIN is one byte but takes 16. Diagram highlights are conceptual data flow, not physical chip layout.

4 KB ROM, sixteen 4-bit registers, accumulator, carry, TEST input, and a four-slot circular PC/return stack. RAM uses an explicitly modeled external 3-to-8 bank decoder: DCL values 0–7 select independent banks, each with four 4002 chips. Physical CM-RAM line combinations are not simulated.

Separate input/output latches model sixteen ROM ports; the switches drive input port 0. WPM is recognized but pauses with an error: a writable-program-memory interface is not installed. No original Busicom ROM is included; all demos are small original 4004 programs.

Keyboard: Space run/pause, S step, B back, R reset. Shortcuts are inactive inside controls. Back restores up to 256 instruction snapshots, including input state.

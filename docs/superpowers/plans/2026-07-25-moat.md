# MOAT Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build MOAT, a single-file HTML facility-management game in which the player keeps twelve crocodiles alive, keeps everyone else out, and prevents the accident.

**Architecture:** One self-contained `game-moat/index.html`. All pure simulation logic lives in a `<script id="shared-code">` block that `test.mjs` extracts by regex and executes in Node, so the whole model is unit-testable with no build step. A second `<script>` block owns the DOM panels, the canvas renderer, and a `requestAnimationFrame` accumulator driving a fixed 1 Hz logic tick. State is one plain `state` object mutated only by reducer functions.

**Tech Stack:** Vanilla JS (ES2020), HTML, CSS custom properties, Canvas 2D, `localStorage`. No dependencies, no build step, no network calls. Node (any recent version) runs `test.mjs`.

**Spec:** `docs/superpowers/specs/2026-07-25-moat-design.md`. Section references below (§2, §5.3, …) point into it.

## Global Constraints

- Single self-contained `game-moat/index.html`; must work offline when opened as a `file://` URL.
- No external dependencies, no CDN links, no network calls, no build step.
- All pure logic goes in `<script id="shared-code">`; UI/render/loop code goes in the second `<script>` block. Logic in the shared block must never touch `document`, `window`, `localStorage`, or `canvas` — it has to run in Node.
- Test registry is named `MoatTests`, exposing `add(name, fn)` and `run()`; `test.mjs` calls `MoatTests.run()` and exits non-zero on failure.
- Randomness only via `rngNext(state)` / `rngInt(state, n)` threaded through `state.rngState`. Never `Math.random()` — runs must be reproducible from the seed.
- 1 logic tick = 1 in-game hour. Speed control 1×/4×/16× plus pause.
- Canvas moat view ~800×500. Canvas backing store must be sized in device pixels (`devicePixelRatio`), never CSS-stretched from a logical-size buffer.
- Tone (§11): deadpan procedural. No winking at the camera, no exclamation-mark comedy, no emoji in event copy. Report-card check marks are the sole exception.
- Commit directly to `main` after each task.
- Run `node test.mjs` from `game-moat/` before every commit; it must print `ALL <n> TESTS PASSED`.

```html
  let t = (state.rngState = (state.rngState + 0x6D2B79F5) >>> 0);
```

```js
// ============ thermal response and the torpor dial ============
function clamp(v, lo, hi) { return v < lo ? lo : v > hi ? hi : v; }
function clamp01(v) { return clamp(v, 0, 1); }
function lerp(a, b, t) { return a + (b - a) * t; }

// Ectotherm response curve. Dead below 16 C, plateau 30-34 C, heat stress above 35 C.
function tempResponse(effTemp) {
  if (effTemp <= 16) return 0;
  if (effTemp < 30) return clamp01((effTemp - 16) / 14);
  if (effTemp <= 34) return 1;
  return clamp01(lerp(1, 0.25, (effTemp - 34) / 8));
}

// Crocodiles are crepuscular/nocturnal: quiet at midday, active at dusk and after dark.
function dielFactor(hour) {
  const h = ((hour % 24) + 24) % 24;
  if (h >= 10 && h < 16) return 0.78;          // midday lull
  if (h >= 19 || h < 2) return 1.18;           // dusk into night
  if (h >= 4 && h < 8) return 1.1;             // dawn
  return 0.95;
}

function computeActivity({ waterTemp, baskingAccess, hunger, hour, seasonFactor, health }) {
  // Basking lets an animal run warmer than the water it sits in.
  const effTemp = waterTemp + 4.5 * clamp01(baskingAccess);
  const thermal = tempResponse(effTemp);
  const appetite = 0.6 + 0.55 * clamp01(hunger);   // hungry animals are alert
  const vigour = 0.45 + 0.55 * clamp01(health);
  const raw = 100 * thermal * appetite * dielFactor(hour) * clamp(seasonFactor, 0.5, 1.2) * vigour;
  return clamp(Math.round(raw), 0, 100);
}

function activityBand(activity) {
  if (activity < 25) return "torpid";
  if (activity < 45) return "low";
  if (activity < 70) return "optimal";
  if (activity < 90) return "aggressive";
  return "frenzied";
}

const BAND_LABEL = {
  torpid: "Torpid", low: "Low", optimal: "Optimal", aggressive: "Aggressive", frenzied: "Frenzied",
};
```

```js
  state.env.waterTemp = waterTempFor(state);
  recomputeActivity(state);
  return state;
}

function logEvent(state, text, kind) {
  state.log.push({ day: state.day, hour: state.hour, text, kind: kind || "info" });
  if (state.log.length > 400) state.log.shift();
}

// ============ environment ============
function ambientTemp(state) {
  const seasonal = Math.sin(((state.day % 360) / 360) * Math.PI * 2) * 6;
  const daily = Math.sin(((state.hour - 9) / 24) * Math.PI * 2) * 5;
  const weatherOffset = { clear: 0, rain: -3, storm: -5, coldsnap: -14, heat: 9 }[state.env.weather] || 0;
  return state.env.baseAmbient !== undefined
    ? state.env.baseAmbient + seasonal + daily + weatherOffset
    : 24 + seasonal + daily + weatherOffset;
}

function waterTempFor(state) {
  // Water lags air and is pulled toward the heater setpoint when heating is on.
  const air = state.env.ambient;
  const set = state.facility.heaterSetpoint;
  if (set <= 0 || !state.env.powered) return set <= 0 ? air : Math.max(air, air);
  return Math.max(air, air + (set - air) * 0.75);
}

function baskingAccessFor(state) {
  const wanting = state.crocs.filter(c => c.present).length;
  if (wanting === 0) return 1;
  const capacity = state.facility.baskingPlatforms;
  const shadePenalty = clamp01(state.facility.shadeCoverage) * 0.25;
  return clamp01(capacity / wanting) * (1 - shadePenalty);
}

function meanOf(state, key) {
  const present = state.crocs.filter(c => c.present);
  if (present.length === 0) return 0;
  return present.reduce((sum, c) => sum + c[key], 0) / present.length;
}
function meanHunger(state) { return meanOf(state, "hunger"); }
function meanHealth(state) { return meanOf(state, "health"); }

function seasonFactorFor(state) {
  return state.env.ambient < 18 ? 0.85 : 1;
}

function recomputeActivity(state) {
  state.activity = computeActivity({
    waterTemp: state.env.waterTemp,
    baskingAccess: baskingAccessFor(state),
    hunger: meanHunger(state),
    hour: state.hour,
    seasonFactor: seasonFactorFor(state),
    health: meanHealth(state),
  });
  return state.activity;
}

// ============ hourly tick ============
function tickHour(state) {
  state.hour++;
  if (state.hour >= HOURS_PER_DAY) { state.hour = 0; state.day++; }

  if (state.env.powered === undefined) state.env.powered = true;
  state.env.ambient = ambientTemp(state);
  state.env.waterTemp = waterTempFor(state);

  // Water quality: waste in, filtration out.
  const load = state.crocs.filter(c => c.present).length * 0.0012;
  const cleared = state.facility.filtration * (state.env.powered ? 0.0035 : 0);
  state.env.ammonia = clamp01(state.env.ammonia + load - cleared);
  // Turbidity tracks ammonia and settles slowly toward what filtration allows.
  const targetTurbidity = clamp01(0.75 - state.facility.filtration * 0.55 + state.env.ammonia * 0.3);
  state.env.turbidity += (targetTurbidity - state.env.turbidity) * 0.02;

  updateCrocs(state);
  recomputeActivity(state);
}

function updateCrocs(state) {
  const feedable = state.env.waterTemp >= 20;
  for (const c of state.crocs) {
    if (!c.present) continue;
    c.bodyTemp += (state.env.waterTemp - c.bodyTemp) * 0.12;
    // Metabolism runs on temperature: cold animals barely burn anything.
    const metabolic = feedable ? 0.0032 * clamp01((state.env.waterTemp - 18) / 14) : 0.0002;
    c.hunger = clamp01(c.hunger + metabolic);

    // Health pressures: ammonia, starvation, crowding stress, cold.
    let drift = 0.0004;                                   // baseline recovery
    if (state.env.ammonia > 0.5) drift -= (state.env.ammonia - 0.5) * 0.0035;
    if (c.hunger > 0.85) drift -= (c.hunger - 0.85) * 0.006;
    if (state.env.waterTemp < 18) drift -= (18 - state.env.waterTemp) * 0.0006;
    if (c.stress > 0.6) drift -= (c.stress - 0.6) * 0.002;
    c.health = clamp01(c.health + drift);

    const crowding = clamp01(1 - baskingAccessFor(state));
    c.stress = clamp01(c.stress + crowding * 0.0015 - 0.0008);

    // Behaviour state, used by the renderer and the census.
    if (state.env.waterTemp < 20) c.state = "submerged";
    else if (state.hour >= 9 && state.hour < 16 && rngNext(state) < 0.35) c.state = "basking";
    else if (rngNext(state) < 0.2) c.state = "hidden";
    else if (state.activity > 55 && rngNext(state) < 0.4) c.state = "patrolling";
    else c.state = "submerged";
  }
}
```

```js
// ============ the morning census ============
const CENSUS_DEPTHS = {
  cursory:  { hours: 0.25, label: "Cursory (15 min)",  revealBonus: 0.0 },
  standard: { hours: 1,    label: "Standard (1 hr)",   revealBonus: 0.3 },
  thorough: { hours: 3,    label: "Thorough (3 hr)",   revealBonus: 0.62 },
};

function censusAvailable(state, depth) {
  if (depth === "thorough") return state.env.turbidity <= 0.3;
  return Boolean(CENSUS_DEPTHS[depth]);
}

// Probability that a present animal is missed by the observer.
function missChance(state, croc, depth) {
  const d = CENSUS_DEPTHS[depth];
  const concealment = croc.state === "hidden" ? 0.25 : croc.state === "submerged" ? 0.15 : 0;
  const base = 0.06 + 0.5 * clamp01(state.env.turbidity) + concealment
    + clamp01(state.staff.fatigue) * 0.12;
  return clamp01(base - d.revealBonus);
}

function runCensus(state, depth) {
  const d = CENSUS_DEPTHS[depth] || CENSUS_DEPTHS.standard;
  state.hours.spent += d.hours;

  const present = state.crocs.filter(c => c.present);
  const missedIds = [];
  for (const c of present) {
    if (rngNext(state) < missChance(state, c, depth)) missedIds.push(c.id);
  }
  const counted = present.length - missedIds.length;
  const expected = state.licensedHeadcount;

  const obs = {
    depth, expected, counted, actualPresent: present.length,
    missedIds, healthFlags: [], kind: "count", low: counted, high: counted,
    short: counted < expected,
  };

  if (depth === "cursory") {
    // Too quick to commit to a number; the observer offers a band around what they saw.
    const spread = 1 + rngInt(state, 2);
    obs.kind = "range";
    obs.low = Math.max(0, counted - spread);
    obs.high = counted + spread;
    obs.short = obs.high < expected;
  }

  if (depth === "thorough") {
    for (const c of present) {
      if (c.health < 0.7) obs.healthFlags.push({ id: c.id, name: c.name, note: "condition below standard" });
      else if (c.hunger > 0.9) obs.healthFlags.push({ id: c.id, name: c.name, note: "has not fed in some time" });
      else if (c.stress > 0.7) obs.healthFlags.push({ id: c.id, name: c.name, note: "showing stress behaviour" });
    }
  }
  return obs;
}

function censusNarrative(state, obs) {
  const clarity = state.env.turbidity > 0.6 ? " Water clarity poor." : "";
  if (obs.kind === "range") {
    return `${obs.low}–${obs.high} animals observed. The count was not held long enough to be worth much.${clarity}`;
  }
  if (!obs.short) {
    const flags = obs.healthFlags.length
      ? ` ${obs.healthFlags.length} animal(s) flagged for review.`
      : "";
    return `${obs.counted} of ${obs.expected} confirmed.${flags}${clarity}`;
  }
  return `${obs.counted} of ${obs.expected} — ${obs.expected - obs.counted} unaccounted.${clarity}`;
}
```

```js
// ============ handler hours: the day's currency ============
const BRIEFING_ACTIONS = [
  { id: "inspect-structure", label: "Inspect a structure", hours: 1.5,
    description: "Reveals true integrity for one perimeter element." },
  { id: "grate-maintenance", label: "Grate and culvert maintenance", hours: 2,
    description: "Restores culvert integrity. Nobody wants to spend the morning on it." },
  { id: "bank-repair", label: "Bank and fence repair", hours: 2.5,
    description: "Restores bank angle and fence line. Silt builds a ramp if left." },
  { id: "vet-visit", label: "Veterinary call-out", hours: 2,
    description: "Treats the worst-affected animal. Costs money as well as hours." },
  { id: "airspace-watch", label: "Airspace watch", hours: 1,
    description: "Someone looks up. Nobody budgets for this." },
  { id: "staff-rest", label: "Rostered rest", hours: 1.5,
    description: "Hours spent not working. Reduces fatigue, which is how incidents start." },
];

function dailyHandlerHours(state) {
  const raw = state.staff.handlers * 6;
  return Math.round(raw * (1 - clamp01(state.staff.fatigue) * 0.45) * 4) / 4;
}

function hoursRemaining(state) {
  return Math.round((state.hours.budget - state.hours.spent) * 100) / 100;
}

function beginDay(state) {
  state.hours.budget = dailyHandlerHours(state);
  state.hours.spent = 0;
  state.hours.allocations = {};
  logEvent(state, `Morning briefing. ${state.hours.budget} handler-hours available.`, "info");
}

function allocateHours(state, actionId, amount) {
  const action = BRIEFING_ACTIONS.find(a => a.id === actionId);
  if (!action) return false;
  const cost = amount === undefined ? action.hours : amount;
  if (cost > hoursRemaining(state) + 1e-9) return false;
  state.hours.spent += cost;
  state.hours.allocations[actionId] = (state.hours.allocations[actionId] || 0) + cost;
  return true;
}

function endDay(state) {
  const load = state.hours.budget > 0 ? clamp01(state.hours.spent / state.hours.budget) : 0;
  const rest = (state.hours.allocations["staff-rest"] || 0) * 0.04;
  state.staff.fatigue = clamp01(state.staff.fatigue + load * 0.12 - 0.07 - rest);
}
```

```js
// ============ containment structures ============
const STRUCTURE_DEFS = [
  { id: "overflow-drain", name: "Overflow and storm drains", decayPerDay: 0.006, escapeRoute: true },
  { id: "culvert-grate",  name: "Culvert grates",            decayPerDay: 0.008, escapeRoute: true },
  { id: "service-bridge", name: "Service bridge",            decayPerDay: 0.004, escapeRoute: false },
  { id: "bank-fence",     name: "Bank angle and fence line", decayPerDay: 0.007, escapeRoute: true },
];

function createStructures(state) {
  return STRUCTURE_DEFS.map(def => ({
    id: def.id, name: def.name,
    integrity: 0.9 + rngNext(state) * 0.1,
    knownIntegrity: null,
    lastInspectedDay: 0,
  }));
}

function decayStructures(state) {
  const weather = state.env.weather;
  for (const st of state.structures) {
    const def = STRUCTURE_DEFS.find(d => d.id === st.id);
    let rate = def.decayPerDay * (0.6 + rngNext(state) * 0.8);
    if (weather === "storm") rate *= st.id === "overflow-drain" ? 3.5 : 1.8;
    else if (weather === "rain") rate *= st.id === "overflow-drain" ? 1.8 : 1.2;
    // Silt builds a ramp: dirty water degrades the bank faster.
    if (st.id === "bank-fence") rate *= 1 + state.env.ammonia;
    st.integrity = clamp01(st.integrity - rate);
  }
}

function inspectStructure(state, id) {
  const st = state.structures.find(x => x.id === id);
  if (!st) return 0;
  st.knownIntegrity = st.integrity;
  st.lastInspectedDay = state.day;
  logEvent(state, `${st.name} inspected. Integrity ${(st.integrity * 100).toFixed(0)} per cent.`, "maintenance");
  return st.integrity;
}

function repairStructure(state, id, amount) {
  const st = state.structures.find(x => x.id === id);
  if (!st) return;
  st.integrity = clamp01(st.integrity + amount);
  st.knownIntegrity = st.integrity;
}

function weakestStructure(state) {
  return state.structures.reduce((a, b) => (a.integrity <= b.integrity ? a : b));
}

function applyBriefingMaintenance(state) {
  const alloc = state.hours.allocations;
  if (alloc["inspect-structure"]) {
    // Inspect whatever has gone longest without being looked at.
    const target = state.structures.reduce((a, b) => (a.lastInspectedDay <= b.lastInspectedDay ? a : b));
    inspectStructure(state, target.id);
  }
  if (alloc["grate-maintenance"]) {
    repairStructure(state, "culvert-grate", 0.35);
    repairStructure(state, "overflow-drain", 0.15);
    logEvent(state, "Replaced grate, culvert 4 (north). Previous grate found displaced, not damaged. No animals unaccounted for at time of inspection. Recommend reviewing what displaced it.", "maintenance");
  }
  if (alloc["bank-repair"]) {
    repairStructure(state, "bank-fence", 0.4);
    repairStructure(state, "service-bridge", 0.2);
  }
}
```

```js
function incidentWeights(state) {
  return INCIDENTS
    .map(incident => ({ incident, weight: incident.weight(state) }))
    .filter(w => w.weight > 0);
}

function pickIncident(state) {
  const weights = incidentWeights(state);
  if (weights.length === 0) return null;
  const total = weights.reduce((sum, w) => sum + w.weight, 0);
  let roll = rngNext(state) * total;
  for (const w of weights) {
    roll -= w.weight;
    if (roll <= 0) return w.incident;
  }
  return weights[weights.length - 1].incident;
}

function applyIncident(state, incident) {
  incident.apply(state);
}

function maybeFireIncident(state) {
  // Roughly one incident every other day, rising with neglect.
  const pressure = 0.35
    + (1 - meanHealth(state)) * 0.4
    + clamp01(state.staff.fatigue) * 0.3
    + (1 - weakestStructure(state).integrity) * 0.3;
  if (rngNext(state) > clamp01(pressure)) return null;
  const incident = pickIncident(state);
  if (incident) applyIncident(state, incident);
  return incident;
}

function applyVetVisit(state) {
  if (!state.hours.allocations["vet-visit"]) return;
  const present = state.crocs.filter(c => c.present);
  if (present.length === 0) return;
  const worst = present.reduce((a, b) => (a.health <= b.health ? a : b));
  worst.health = clamp01(worst.health + 0.3);
  worst.stress = clamp01(worst.stress - 0.2);
  state.money -= 1200;
  logEvent(state, `Veterinary call-out. ${worst.name} examined and treated.`, "maintenance");
}

function resolvePending(state) {
  const due = state.pending.filter(p => p.day <= state.day);
  state.pending = state.pending.filter(p => p.day > state.day);
  for (const p of due) {
    if (p.kind === "power-restored") {
      state.env.powered = true;
      logEvent(state, "Supply restored. Pumps and heaters back on line.", "info");
    } else if (p.kind === "bloom-worsens") {
      state.env.ammonia = clamp01(state.env.ammonia + 0.3);
      state.ledger.welfareFindings++;
      logEvent(state, "Water quality has continued to deteriorate. This is now documented.", "serious");
    } else if (p.kind === "sighting-reported") {
      const c = state.crocs.find(x => x.id === p.crocId);
      logEvent(state, `A member of the grounds staff reports seeing an animal outside the perimeter, near the service road. ${c ? c.name : "One animal"} remains unaccounted for.`, "serious");
      state.satisfaction -= 15;
      state.ledger.serious++;
    }
  }
```

```js
function resolveHandlerIncident(state, severityBase) {
  const skill = 0.5 + Math.min(state.staff.handlers, 6) * 0.08;
  const exposure = clamp01(state.activity / 100);
  const margin = skill - clamp01(state.staff.fatigue);
  const risk = clamp01(severityBase * exposure * (1 - margin) * 2.2);
  const roll = rngNext(state);
  const injured = roll < risk;
  // A torpid animal cannot hurt anyone; handlers work in the water at this level.
  const fatal = injured && state.activity >= 70 && rngNext(state) < risk * 0.35;
  if (fatal) {
    state.ledger.fatal++; state.ledger.fatalities++;
    state.satisfaction -= 25;
  } else if (injured) {
    state.ledger.serious++;
    state.satisfaction -= 6;
  }
  return { injured, fatal };
}
```

```js
function feedSchedulePredictable(state) {
  const log = state.feedTimesLog;
  if (log.length < 3) return state.facility.feedIntervalDays <= 6;
  const gaps = [];
  for (let i = 1; i < log.length; i++) gaps.push(log[i] - log[i - 1]);
  const mean = gaps.reduce((a, b) => a + b, 0) / gaps.length;
  const variance = gaps.reduce((a, g) => a + (g - mean) ** 2, 0) / gaps.length;
  return variance < 1.5;
}

function pickIntrusionMethod(state) {
  const weighted = INTRUSION_METHODS.map(m => ({ m, v: m.viability(state) })).filter(x => x.v > 0.01);
  if (weighted.length === 0) return INTRUSION_METHODS[0];
  const total = weighted.reduce((sum, x) => sum + x.v, 0);
  let roll = rngNext(state) * total;
  for (const x of weighted) {
    roll -= x.v;
    if (roll <= 0) return x.m;
  }
  return weighted[weighted.length - 1].m;
}

function resolveIntrusion(state, method) {
  state.ledger.breaches++;
  const success = rngNext(state) < method.viability(state);
  // Guards and watch coverage decide whether you ever find out.
  const watch = clamp01(state.staff.guards * 0.22 + (state.hours.allocations["airspace-watch"] ? 0.15 : 0));
  const detected = rngNext(state) < clamp01(watch + (success ? 0.25 : 0.55));
  const narrative = method.narrative(state, { success });

  if (success) {
    state.ledger.breachesSuccessful++;
    state.satisfaction -= state.contract && state.contract.egress ? 25 : 15;
  }
  if (detected) {
    logEvent(state, narrative, success ? "serious" : "minor");
    state.ledger[success ? "serious" : "minor"]++;
  } else if (success) {
    addRedFlag(state, `A successful ${state.contract && state.contract.egress ? "egress" : "entry"} on day ${state.day} was never detected: ${method.label.toLowerCase()}.`);
  }
  return { success, detected, narrative };
}

function maybeAttemptIntrusion(state) {
  const base = state.contract ? state.contract.intrusionRate : 0.18;
  const opportunism = clamp01(1 - deterrence(state)) * 0.25;
  if (rngNext(state) > clamp01(base + opportunism)) return null;
  return resolveIntrusion(state, pickIntrusionMethod(state));
}
```

```js
// ============ grading and close-out ============
const LETTERS = ["A", "B", "C", "D", "F"];

function scoreToLetter(score) {
  if (score >= 0.85) return "A";
  if (score >= 0.7) return "B";
  if (score >= 0.55) return "C";
  if (score >= 0.4) return "D";
  return "F";
}

function welfareGrade(state) {
  const health = meanHealth(state);
  const water = 1 - clamp01(state.env.ammonia);
  const stocking = clamp01(baskingAccessFor(state));
  const findings = state.ledger.welfareFindings;
  const critical = state.ledger.welfareCritical;
  let score = health * 0.5 + water * 0.25 + stocking * 0.25 - findings * 0.05;
  if (critical > 0) score = 0;
  return { letter: scoreToLetter(clamp01(score)), findings, critical };
}

function contractOver(state) {
  return state.status !== "running" || state.day > state.contractDays;
}

function gradeContract(state) {
  const welfare = welfareGrade(state);
  const present = state.crocs.filter(c => c.present).length;
  const containment = clamp01(1 - state.ledger.breachesSuccessful * 0.3 - state.ledger.breaches * 0.04);
  const incidentPenalty = clamp01(state.ledger.minor * 0.015 + state.ledger.serious * 0.06 + state.ledger.fatal * 0.5);
  const welfareScore = 1 - LETTERS.indexOf(welfare.letter) * 0.22;
  const satisfaction = clamp01(state.satisfaction / 100);

  let score = clamp01(welfareScore * 0.35 + containment * 0.3 + satisfaction * 0.2 + (1 - incidentPenalty) * 0.15);
  let letter = scoreToLetter(score);
  let hardGated = null;

  if (welfare.critical > 0) {
    letter = "F";
    hardGated = "Critical welfare finding. The licence was suspended.";
  } else if (state.ledger.fatalities > 0) {
    if (LETTERS.indexOf(letter) < LETTERS.indexOf("D")) letter = "D";
    hardGated = "A fatality occurred. No other figure on this page changes that.";
  } else if (state.ledger.lostAnimals > 0) {
    if (LETTERS.indexOf(letter) < LETTERS.indexOf("D")) letter = "D";
    hardGated = "An animal left the facility. No other figure on this page changes that.";
  }

  return {
    client: state.contract ? state.contract.name : state.clientId,
    site: state.contract ? state.contract.site : "",
    days: Math.min(state.day, state.contractDays),
    welfare, breaches: state.ledger.breaches,
    breachesSuccessful: state.ledger.breachesSuccessful,
    incidents: { minor: state.ledger.minor, serious: state.ledger.serious, fatal: state.ledger.fatal },
    satisfaction: Math.round(clamp01(state.satisfaction / 100) * 100),
    censusFinal: { counted: present, expected: state.licensedHeadcount, ok: present >= state.licensedHeadcount },
    redFlags: state.redFlags.length,
    letter, hardGated, seed: state.seed,
  };
}

function renderReportCard(r) {
  const pad = (label, value) => label.padEnd(27) + value;
  const lines = [
    `CONTRACT CLOSE-OUT: ${(r.site || r.client).toUpperCase()}`,
    "",
    pad("Days operated", String(r.days)),
    pad("Animal welfare grade", `${r.welfare.letter}     (${r.welfare.findings} findings, ${r.welfare.critical} critical)`),
    pad("Containment record", `${r.breaches} breach${r.breaches === 1 ? "" : "es"}, ${r.breachesSuccessful} successful`),
    pad("Incidents", `${r.incidents.minor} minor, ${r.incidents.serious} serious, ${r.incidents.fatal} fatal`),
    pad("Client satisfaction", `${r.satisfaction}%`),
    pad("Final census", `${r.censusFinal.counted} of ${r.censusFinal.expected}  ${r.censusFinal.ok ? "✅" : "❌"}`),
    pad("Overall", r.letter),
    pad("Seed", String(r.seed)),
  ];
  if (r.redFlags > 0) {
    lines.push("", `⚠️  Uncategorized red flags: ${r.redFlags}`);
  }
  if (r.hardGated) lines.push("", r.hardGated);
  return lines.join("\n");
}
```

```markdown
# MOAT

A facility-management game about keeping twelve crocodiles alive and everybody else out.

You are the facility manager for a firm that installs live-crocodile security moats
for clients with more money than judgement. You did not design the product. You did
not sell it. You are the person standing beside it at 6 a.m. with a clipboard,

shade, depth, filtration and the feed schedule, and it falls out of them.

animals and better for deterrence, and it is why you cannot count them.
```

# Inmos T414 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** Build `inmos-t414/index.html`, a network of T414 transputers
programmed in a small occam, as Silicon Observatory No. 007.

**Architecture:** Built from scratch part files concatenated into
`index.html`, as for `mit-scheme-79`:

- `engine.part.js`: Transputer, Link, Network;
- `asm.part.js`: assembler and disassembler;
- `occam.part.js`: the compiler;
- `demos.part.js`;
- `tests.part.js`;
- `page.part.html`;
- `ui.part.js`.

## Global constraints

- T414 Table 4.x cycle counts.
- CWG semantics for scheduling, channels and ALT.
- Every page-own part listed in the spec is labelled on the page.

### Task 1: Transputer core
- [ ] Registers, memory, and decode with pfix/nfix/opr.
- [ ] All implemented instructions, with their cycles.
- [ ] Queues, the timeslice, interrupt and restore, timers, channels and ALT.
- [ ] Tests from the CWG predicates. Commit.

### Task 2: Links and network
- [ ] Event-driven wires with bit records and the T414 ack timing.
- [ ] The host, boot from link, and the discrete-event network loop.
- [ ] Tests: throughput, boot, and deadlock detection. Commit.

### Task 3: Assembler and disassembler
- [ ] Prefix relaxation, labels and directives. Round-trip tests. Commit.

### Task 4: Occam compiler
- [ ] Lexer, parser, workspace allocation and codegen for every construct in
      the spec, with a source map. Tests for each construct. Commit.

### Task 5: Demos, UI, README, screenshot, gallery
- [ ] Eight demos, each with an end-to-end test.
- [ ] The UI panels.
- [ ] Verification in the browser and at phone width.
- [ ] Screenshot, `build_gallery.py`, memory update. Commit.

# Swarm Genetic Programming Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A dependency-free Rust crate (grid world, swarm DSL interpreter, function registry, courses, GA, library), compiled to wasm and embedded in a self-contained page that evolves and replays swarm programs.

**Architecture:** One Rust crate in `swarm-genetic-programming/rust/`, `crate-type = ["cdylib", "rlib"]`, so `cargo test` runs natively and `cargo build --target wasm32-unknown-unknown` produces the page's engine. The engine talks to JS through plain `extern "C"` exports and wasm memory (no wasm-bindgen). `build.sh` base64-embeds the `.wasm` into `swarm_wasm.js`, which `index.html` loads with a classic `<script>` (file://-safe).

**Tech Stack:** Rust 1.87 (std, no crates), wasm32-unknown-unknown, vanilla JS + canvas, Node for `test.mjs`.

**Spec:** `docs/superpowers/specs/2026-10-27-swarm-genetic-programming-design.md`

## Global Constraints

- No external crates; `cargo test` must work offline.
- A creature occupies exactly one cell; never two creatures in one cell.
- Grid coordinates are `u16` (x right, y down, origin top-left).
- 16 registers `$0..$15`, `i64`, persist between ticks.
- Exactly one loop: `lpb <src>` … `lpe`, count read once at entry, clamped 0..=255, nest depth ≤ 4. No goto, no break, no conditional jump.
- Call syntax `f<in><out> $target,$source`: function id = value of `$source`; inputs `$source+1 … $source+in`; outputs `$target … $target+out-1`.
- Instruction cap 200 executed instructions per creature per tick (loop iterations count); at most one move per creature per tick.
- Arithmetic is checked; div/mod by 0 and overflow are errors that end the creature's tick.
- Deterministic for a given seed.
- Verified = ≥ 80% of the swarm out of the exit within the tick limit on each of 8 held-out validation seeds.
- Library keeps the top 5 verified programs per course.
- Page works from file:// and GitHub Pages without a build step; localStorage wrapped in try/catch; HiDPI canvas; light and dark themes; original visuals (nothing from the episode).

## Review Focus

1. Malformed program text pasted into the page (library import, replay editor) → a readable parse error with line number, never a wasm trap. Test in Task 1 (`parse_errors_have_line_numbers`) and Task 6 (`test.mjs` loads bad text and gets an error code).
2. `lpb 255` nested four deep → the tick ends at the instruction cap; the page never hangs. Test in Task 2 (`nested_max_loops_hit_cap`).
3. `mul` overflow with large polynomial values → error ends the tick, no panic in wasm. Test in Task 2 (`overflow_ends_tick_keeps_earlier_writes`).
4. More swarm members than spawn cells, or a jam in the one-cell corridor → spawn is capped, no shared cells, no deadlock panic. Test in Task 3 (`spawn_capped_to_spawn_cells`, `no_shared_cells_random_programs`).
5. Register ranges at the edge (`f13 $14,$0`, `f21 $0,$14`) → parse error, not an out-of-bounds index. Test in Task 1 (`call_register_range_checked`).

## File Structure

```
swarm-genetic-programming/
  index.html            page: loader, canvas, controls, panels
  swarm_wasm.js         generated by build.sh: globalThis.SWARM_WASM_BASE64 = "...";
  build.sh              cargo build --release --target wasm32-unknown-unknown + embed
  test.mjs              Node smoke test of the embedded wasm
  screenshot1.jpg
  rust/
    Cargo.toml
    .gitignore          target/
    src/
      lib.rs            module declarations
      rng.rs            Rng (splitmix64 seeding + xoshiro256**)
      program.rs        Instruction, Program, parse, serialize
      interp.rs         Host trait, run()
      registry.rs       function ids, signatures, names; dispatch into World
      path.rs           BFS pathfinding with node budget and corner rule
      course.rs         Course definitions (ASCII maps + params)
      world.rs          World, Creature, Station, tick
      fitness.rs        evaluate(), verify(), Score
      reference.rs      hand-written reference programs (text)
      ga.rs             random programs, mutation, crossover, Evolver
      library.rs        Library (top 5 verified per course), text format
      ffi.rs            extern "C" exports and the global state
```

Pathfinding is BFS rather than A*: every move costs 1 (Chebyshev), so BFS gives the same shortest paths, needs no heuristic, and serves the multi-target searches (`walk_to_kind`, nearest creature) too. The 4096-node budget from the spec applies.

### Task 3: World, courses, pathfinding, registry v1

**Files:** Create `src/{rng.rs (exists), path.rs, course.rs, world.rs, registry.rs}`

**Interfaces — Produces:**
- Kinds (u8): `EMPTY 0, WALL 1, CREATURE 2, FOOD 3, STATION 4, STATION_SOLVED 5, GATE 6, EXIT 7` (+ `TABLET 8` in Task 8).
- `struct Course { name: &'static str, description: &'static str, map: &'static str, swarm: usize, energy: i64, food_energy: i64, ticks: u32, task: TaskSpec, sense_radius: Option<u16>, mix: Option<&'static str> }`; `struct TaskSpec { degree: u8, coef: (i64,i64), x: (i64,i64), tol: i64 }`; `fn courses() -> &'static [Course]` (built once via `OnceLock`). Map chars: `#` wall, `.` empty, `S` spawn, `E` exit, `F` food, `P` station, `G` gate (linked to the nearest `P` by Chebyshev distance, ties by lower index).
- Courses v1 (40×24 or smaller maps; builder draws them): 0 Open field, 1 Wall, 2 Corridor (one-cell corridor ≥ 12 long), 3 Gate sum (degree 1, x fixed 1, coef 0..9, tol 0), 4 Gate line (degree 1, x −9..9, coef −9..9, tol 0), 5 Gate quadratic (degree 2, x −9..9, coef −9..9, tol 0), 6 Food (energy too low to reach the exit without eating at least one food; food off the direct route). Swarm 12, ticks ~150–250 per course.
- `struct Creature { id: u32, x: u16, y: u16, regs: [i64;16], energy: i64, state: CreatureState, moved: bool, acc: (i32,i32), prog: usize }`, `enum CreatureState { Active, Out, Exhausted }`.
- `struct Station { id: u32, x: u16, y: u16, params: [i64;5] /* x,a0..a3 */, solved: bool, best_err: i64, gates: Vec<usize> }`.
- `struct World { w: u16, h: u16, kind: Vec<u8>, id: Vec<u32>, creatures: Vec<Creature>, stations: Vec<Station>, rng: Rng, tick: u32, course: usize, programs: Vec<Program>, food_eaten: u32, flags: Flags }`; `World::new(course: usize, seed: u64, programs: Vec<Program>) -> World` (spawns `min(swarm, spawn cells)` creatures on RNG-chosen spawn cells, all `prog = 0` unless the course has `mix`); `world.step()` (one tick: shuffled order; per active creature: energy −1, if 0 → Exhausted; reset `moved`; `interp::run` with a Host borrowing the world and creature index); `world.done() -> bool` (no active creatures or tick limit); `world.arrived() -> usize`.
- `path::first_step(world_cells, from, goal_test, budget) -> PathResult { Arrived, Step(u16,u16), Blocked }` — BFS over 8 neighbours; passable = EMPTY, FOOD, EXIT; diagonal only if neither orthogonal neighbour is WALL or GATE; within `sense_radius` when set.
- Registry ids exactly as the spec's table (0 my_position … 11 give_food). `registry::signature(id: i64) -> Option<(u8,u8)>`, `registry::name(id) -> &'static str`. Status codes: `1` arrived, `0` moved, `−1` blocked/no path, `−2` already moved. Arrival test per function as in the spec; stepping onto FOOD eats it (+food_energy), stepping onto EXIT → `Out` and the cell is freed. `step` direction table: unit vectors ×1024 with 0 = +x, 4 = −y, counter-clockwise; accumulator algorithm: `acc += v; dx = round(acc.x/1024) clamped −1..1` (same for y); move if the cell is free, then `acc −= (dx,dy)·1024`; if blocked, undo the add and return −1.
- `read_task`: adjacent (Chebyshev 1) unsolved station with lowest id. `submit_answer`: same station; truth `a0+a1x+a2x²+a3x³` (checked i64); updates `best_err`; within `tol` → solved, gates become EMPTY. `give_food(amount)`: adjacent active creature with the lowest energy; amount clamped to `0..=energy−1`.
- Station params drawn from the world RNG at `World::new` (fixed per seed).

- [ ] Step 1: tests (world built from small inline maps through a `World::from_map(map, params, seed, programs)` test constructor): `bfs_goes_around_wall`, `bfs_goes_around_creature`, `no_corner_cutting`, `step_heading_1_averages_22_5_degrees` (16 steps from open field → dx ≈ 15, dy ≈ −6 ±1), `step_blocked_returns_minus_1`, `second_move_returns_minus_2`, `exit_frees_cell_and_counts`, `food_eaten_adds_energy`, `exhausted_creature_blocks`, `walk_to_kind_station_arrives_adjacent`, `walk_from_nearest_creature_increases_distance`, `sense_nearest_returns_id_and_distance`, `walk_to_id_follows_creature`, `read_task_and_submit_open_gate`, `submit_outside_tolerance_records_best_err`, `give_food_transfers_energy`, `unknown_function_ends_tick`, `spawn_capped_to_spawn_cells`, `no_shared_cells_random_programs` (50 random programs × 3 seeds × full course 2 run: after every tick, every active/exhausted creature position unique and `kind` matches), `deterministic_for_seed` (same seed → identical creature positions after 100 ticks), `every_course_map_parses` (each course: has S, E; gates linked; swarm ≤ spawn cells).

### Task 4: Fitness, verification, reference programs

**Files:** Create `src/{fitness.rs, reference.rs}`

**Interfaces — Produces:**
- `struct Score { pub fitness: f64, pub arrived_frac: f64, pub solved_frac: f64, pub ticks_used: u32 }`
- `fn evaluate(course: usize, programs: &[Program], seeds: &[u64]) -> Score` — mean over seeds of: `1000·arrived_frac + 200·solved_frac + 50·food_frac + 100·progress + 50·answer_closeness − 0.5·program_len − 20·ticks_used/ticks`. `progress` = mean over non-arrived creatures of `1 − path_dist_to_exit/initial_path_dist` (clamped 0..1; path distance by BFS ignoring creatures, gates count as passable). `answer_closeness` = mean over unsolved stations of `1/(1+best_err)` (0 if never answered). Weights documented in one doc comment.

- `fn verify(course: usize, programs: &[Program]) -> bool` — ≥ 80% arrived on each validation seed.
- `reference::program_for(course: usize) -> Option<&'static str>` — hand-written program text for every course (needed for 5–6, written for all as a sanity floor).

### Task 5: Genetic algorithm and library

**Files:** Create `src/{ga.rs, library.rs}`

**Interfaces — Produces:**
- `fn random_program(rng: &mut Rng, len: usize) -> Program` — valid; biased toward `mov $r,<registry id or kind>` followed by a matching call.
- `fn mutate(p: &Program, rng: &mut Rng) -> Program` — one of: change constant (±1, ±small, or a registry id / kind 3..7), change register, change op, insert random instruction, insert call pair (`mov $s,<id>` + matching `f<in><out> $t,$s`), delete, swap two, wrap a range in `lpb`/`lpe`, unwrap a loop. Result always passes `validate`; max length 40.
- `fn crossover(a: &Program, b: &Program, rng: &mut Rng) -> Program` — single-point on instruction lists, repaired (unbalanced `lpe` dropped, missing `lpe` appended).
- `struct Evolver { course, rng, population: Vec<(Program, Score)>, generation: u32, history: Vec<f64>, best: (Program, Score), verified_best: Option<Program>, steps_in_gen: u32 }`; `Evolver::new(course, seed, seeds_from_library: Vec<Program>) -> Evolver` (population 200: library programs first, rest random); `step(&mut self, library: &mut Library)` — one child: tournament k=4, 30% crossover then mutate, else mutate; evaluate on `TRAIN_SEEDS`; replace the worse of a random tournament if child ≥ it; on a new best fitness run `verify` and on success `library.offer(course, program, score)`. After `population.len()` steps, `generation += 1` and push best fitness to `history`.
- `struct Library { entries: Vec<Vec<Entry>> }` per course, `Entry { program: Program, fitness: f64, generation: u32 }`; `offer(course, program, fitness, generation) -> bool` (keep top 5 by fitness desc then length asc; dedupe by serialized text); `to_text() -> String` (blocks `; course <i> <name>\n; fitness <f> generation <g>\n<program>\n`), `from_text(&str) -> Result<Library, ParseError>`; `seeds_for(course) -> Vec<Program>` (all entries of other courses, best first).

- [ ] Step 1: tests: `mutation_always_valid` (10 000 mutations from random programs), `crossover_always_valid`, `random_programs_valid_and_run` (they run on course 0 without panic), `ga_clears_course_0` (seed 7, at most 30 generations → `verified_best.is_some()`), `library_keeps_top5_sorted`, `library_text_round_trip`, `library_dedupes`.
- [ ] Step 2: fail → implement → pass. Run `cargo test --release` for the GA test if debug is slow.
- [ ] Step 3: commit `swarm-genetic-programming: genetic algorithm and program library`.

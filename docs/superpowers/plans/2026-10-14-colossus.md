# Colossus Codebreaking Simulator Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A self-contained `colossus/index.html` where a visitor operates a simulated Colossus through a guided break of a Lorenz (Tunny) message — 1+2 break-in, short runs, de-chi, narrated Testery — while the machine's tape loop, valves, counters, typewriter and sound show it working.

**Architecture:** A pure engine in `<script id="shared-code">` (ITA2, Lorenz SZ42, invented German messages, language statistics, Colossus runs, de-chi/Testery) is unit-tested in Node via `test.mjs`. The page renders an SVG machine view (bedstead tape loop, valve racks, panels, counters, typewriter), a close-up canvas of the tape reader, a guided step panel, and a synthesized Web Audio soundscape; a controller turns precomputed run counts into timed tape passes.

**Tech Stack:** Vanilla HTML/CSS/JS, SVG, Canvas 2D, Web Audio. No dependencies, no assets. Node for `test.mjs`; headless Chrome for screenshots.

**Spec:** `docs/superpowers/specs/2026-10-14-colossus-design.md`

## Global Constraints

- One self-contained `colossus/index.html` (offline, no CDN, no assets) + `colossus/test.mjs` + `colossus/screenshot1.jpg` (1600×1000).
- Engine in `<script id="shared-code">` exposing `Colossus` and `ColossusTests.run()`; `test.mjs` extracts it by regex (pattern of `epson-mx80/test.mjs`).
- Lorenz SZ42: χ 41, 31, 29, 26, 23; ψ 43, 47, 51, 53, 59; μ 61, 37. Z = P ⊕ χ ⊕ ψ′. No "limitations".
- ITA2 in Bletchley shiftless notation, • = dot (0), x = cross (1); 9 space, 3 CR, 4 LF, / null, 5 figure shift, 8 letter shift.
- 1+2 break-in counts dots of ΔZ1 ⊕ ΔZ2 ⊕ Δχ1 ⊕ Δχ2 over all 41 × 31 = 1271 starting pairs; set total = n/2 + 2.5σ with σ = √n / 2. Positions are typed numbered from 01.
- Tape speed 5,000 characters per second; Mk 2 tests five settings per pass, Mk 1 one. Speeds: real, 10×, 100×, instant.
- German messages invented (no real persons or orders); every message has an English translation.
- Honesty panel states: wheel patterns assumed known; Testery narrated (true ψ/motor settings applied); no limitations; machine look is an illustrative composite; short-run statistic simplified; sounds synthesized.
- Sound off until the first Start (unless the user touched the toggle); volume slider.
- Commit to `main`; end commit messages with your own model's `Co-Authored-By:` line.

## Review Focus

- Visitor picks a wrong line → the Testery output is garbage, the page says so and offers a way back to the printout/short runs; nothing crashes and earlier picks stay consistent (Task 5).
- Stop, or changing model/speed, in the middle of a run → progress, counters and typed lines stay consistent and the run can continue (Task 5).
- 100× speed with a low set total → hundreds of typed lines; the typewriter must catch up (within a few seconds of the run ending) rather than lag for minutes (Task 4 + Task 5).
- "New intercept" during a run → the run is cancelled, sound stops, panels and paper reset (Task 5).
- Set total edited to an extreme → 0 prints every setting quickly; above the maximum prints nothing and the page tells the visitor to lower it and run again (Task 5).

- [ ] **Step 3: Implement the engine** — replace the `Colossus` IIFE with exactly this code (it was prototyped and measured: 60/60 1+2 hits, 59/60 full breaks, ΔD1⊕ΔD2 dot rate 0.559):

```js
const Colossus = (() => {
  const SIZES = { chi: [41, 31, 29, 26, 23], psi: [43, 47, 51, 53, 59], mu: [61, 37] };

  // mulberry32: every puzzle is reproducible from its seed
  function rng(seed) {
    let a = seed >>> 0;
    return () => { a = (a + 0x6d2b79f5) >>> 0; let t = a; t = Math.imul(t ^ (t >>> 15), t | 1); t ^= t + Math.imul(t ^ (t >>> 7), t | 61); return ((t ^ (t >>> 14)) >>> 0) / 4294967296; };
  }

  // ---- teleprinter code: ITA2 in Bletchley Park's shiftless notation -------------------------
  // Impulses 1..5 left to right, x = cross (1), . = dot (0). 9 space, 3 carriage return, 4 line feed,
  // / null, 5 figure shift, 8 letter shift.
  const ITA2 = { A: "xx...", B: "x..xx", C: ".xxx.", D: "x..x.", E: "x....", F: "x.xx.", G: ".x.xx", H: "..x.x", I: ".xx..", J: "xx.x.",
    K: "xxxx.", L: ".x..x", M: "..xxx", N: "..xx.", O: "...xx", P: ".xx.x", Q: "xxx.x", R: ".x.x.", S: "x.x..", T: "....x",
    U: "xxx..", V: ".xxxx", W: "xx..x", X: "x.xxx", Y: "x.x.x", Z: "x...x", 9: "..x..", 3: "...x.", 4: ".x...", "/": ".....", 5: "xx.xx", 8: "xxxxx" };
  const CODE = {}, CHAR = [];
  for (const [ch, s] of Object.entries(ITA2)) { let v = 0; for (let i = 0; i < 5; i++) if (s[i] === "x") v |= 1 << i; CODE[ch] = v; CHAR[v] = ch; }
  const toCodes = (text) => Uint8Array.from([...text].filter((c) => c in CODE), (c) => CODE[c]);
  const toText = (codes) => Array.from(codes, (v) => CHAR[v]).join("");
  const dotCross = (v) => Array.from({ length: 5 }, (_, i) => ((v >> i) & 1 ? "x" : "•")).join("");

  // ---- the Lorenz SZ42 (without "limitations") --------------------------------------------------
  // Random pin patterns with no run longer than four (a German pattern rule of thumb). The 37 motor
  // wheel has about 30% crosses, so the psi wheels stall about 70% of the time: the weakness Tutte used.
  function pattern(n, r, crosses = .5) {
    const p = [];
    for (let i = 0; i < n; i++) { let b = r() < crosses ? 1 : 0; if (i >= 4 && p[i - 1] === b && p[i - 2] === b && p[i - 3] === b && p[i - 4] === b) b ^= 1; p.push(b); }
    return p;
  }
  const makeKey = (r) => ({ chi: SIZES.chi.map((n) => pattern(n, r)), psi: SIZES.psi.map((n) => pattern(n, r)), mu: [pattern(61, r, .6), pattern(37, r, .3)] });
  const randomStart = (r) => ({ chi: SIZES.chi.map((n) => Math.floor(r() * n)), psi: SIZES.psi.map((n) => Math.floor(r() * n)), mu: SIZES.mu.map((n) => Math.floor(r() * n)) });
  // Key streams for n characters: chi every character; mu61 every character; mu37 when mu61 shows a
  // cross; the psi wheels together when mu37 shows a cross (so psi' repeats while they stall).
  function keystream(key, start, n) {
    const c = start.chi.slice(), p = start.psi.slice(), chi = new Uint8Array(n), psi = new Uint8Array(n);
    let m61 = start.mu[0], m37 = start.mu[1];
    for (let i = 0; i < n; i++) {
      for (let k = 0; k < 5; k++) { chi[i] |= key.chi[k][c[k]] << k; psi[i] |= key.psi[k][p[k]] << k; }
      const psiMoves = key.mu[1][m37], m37Moves = key.mu[0][m61];
      for (let k = 0; k < 5; k++) c[k] = (c[k] + 1) % SIZES.chi[k];
      if (psiMoves) for (let k = 0; k < 5; k++) p[k] = (p[k] + 1) % SIZES.psi[k];
      if (m37Moves) m37 = (m37 + 1) % 37;
      m61 = (m61 + 1) % 61;
    }
    return { chi, psi };
  }
  // Z = P + chi + psi' (bitwise mod 2); the same operation deciphers.
  function encipher(codes, key, start) { const ks = keystream(key, start, codes.length); return codes.map((v, i) => v ^ ks.chi[i] ^ ks.psi[i]); }

  // ---- invented German messages in teleprinter style ------------------------------------------
  const PICK = (r, a) => a[Math.floor(r() * a.length)];
  // [name, grammatical gender, English]; places as [dative, accusative, English].
  const UNITS = [["PANZERDIVISION", "f", "armoured division"], ["INFANTERIEREGIMENT", "n", "infantry regiment"], ["PIONIERBATAILLON", "n", "engineer battalion"], ["ARTILLERIEABTEILUNG", "f", "artillery battalion"], ["NACHRICHTENKOMPANIE", "f", "signals company"]];
  const PLACES = [["DER BRUECKE OSTWAERTS", "DIE BRUECKE OSTWAERTS", "the bridge to the east"], ["HOEHE 207", "HOEHE 207", "hill 207"], ["DEM DORF AM FLUSS", "DAS DORF AM FLUSS", "the village by the river"], ["DEM WALDRAND NORDWESTLICH", "DEN WALDRAND NORDWESTLICH", "the north-western edge of the forest"], ["DER STRASSENKREUZUNG", "DIE STRASSENKREUZUNG", "the crossroads"]];
  const SUPPLIES = [["TREIBSTOFF", "fuel"], ["MUNITION", "ammunition"], ["VERPFLEGUNG", "rations"], ["ERSATZTEILE", "spare parts"]];
  const nom = (u) => (u[1] === "f" ? "DIE " : "DAS ") + u[0], gen = (u) => (u[1] === "f" ? "DER " + u[0] : "DES " + u[0] + "S");
  const ordinal = (n) => n + (n % 100 >= 11 && n % 100 <= 13 ? "th" : ["th", "st", "nd", "rd"][n % 10] || "th");
  const SENTENCES = [
    (r) => { const u = PICK(r, UNITS), n = 2 + Math.floor(r() * 30), p = PICK(r, PLACES), h = 10 + Math.floor(r() * 13);
      return [`${u[1] === "f" ? "DIE" : "DAS"} ${n}. ${u[0]} ERREICHT ${p[1]} UM ${h} UHR.`, `The ${ordinal(n)} ${u[2]} reaches ${p[2]} at ${h}:00.`]; },
    (r) => { const s = PICK(r, SUPPLIES), t = 20 + Math.floor(r() * 80); return [`NACHSCHUB VON ${t} TONNEN ${s[0]} VERZOEGERT.`, `Delivery of ${t} tonnes of ${s[1]} delayed.`]; },
    (r) => { const p = PICK(r, PLACES); return [`FEINDLICHE ARTILLERIE BESCHIESST ${p[1]}.`, `Enemy artillery is shelling ${p[2]}.`]; },
    (r) => { const p = PICK(r, PLACES); return [`STELLUNG AN ${p[0]} WIRD GEHALTEN. VERLUSTE GERING.`, `The position at ${p[2]} is being held. Losses light.`]; },
    (r) => { const u = PICK(r, UNITS); return [`ERBITTE WEISUNG FUER DEN WEITEREN EINSATZ ${gen(u)}.`, `Request orders for the further deployment of the ${u[2]}.`]; },
    (r) => { const p = PICK(r, PLACES); return [`UEBERGANG BEI ${p[0]} GESICHERT.`, `The crossing at ${p[2]} is secured.`]; },
    (r) => { const s = PICK(r, SUPPLIES), n = 3 + Math.floor(r() * 9); return [`BESTAND AN ${s[0]} REICHT NUR NOCH FUER ${n} TAGE.`, `Stocks of ${s[1]} will last only ${n} more days.`]; },
    (r) => { const u = PICK(r, UNITS); return [`WETTER: REGEN, STRASSEN SCHLECHT BEFAHRBAR. ${nom(u)} MELDET VERZOEGERUNG.`, `Weather: rain, roads barely passable. The ${u[2]} reports a delay.`]; }
  ];
  const FIGS = { 1: "Q", 2: "W", 3: "E", 4: "R", 5: "T", 6: "Y", 7: "U", 8: "I", 9: "O", 0: "P", ".": "M", ",": "N", ":": "C", "-": "A" };
  // Operators' habits: 9 for space (often doubled), digits and punctuation inside doubled figure
  // shifts (55 ... 88), a full stop as 55M88, a new line as 3344. These habits bias the deltas.
  function teleprinter(german, r) {
    let out = "", figs = false;
    for (const ch of german) {
      if (ch === " ") { if (figs) { out += "88"; figs = false; } out += r() < .15 ? "99" : "9"; }
      else if (ch === "\n") { if (figs) { out += "88"; figs = false; } out += "3344"; }
      else if (ch in FIGS) { if (!figs) { out += "55"; figs = true; } out += FIGS[ch]; }
      else if (/[A-Z]/.test(ch)) { if (figs) { out += "88"; figs = false; } out += ch; }
    }
    return out + (figs ? "88" : "");
  }
  // Teleprinter text back to readable German (for the final reveal).
  const FIG_BACK = Object.fromEntries(Object.entries(FIGS).map(([k, v]) => [v, k]));
  function readable(tele) {
    let out = "", figs = false;
    for (const ch of tele) {
      if (ch === "5") figs = true; else if (ch === "8") figs = false;
      else if (ch === "9") out += out.endsWith(" ") ? "" : " ";
      else if (ch === "3" || ch === "4") out += out.endsWith("\n") ? "" : "\n";
      else if (ch !== "/") out += figs ? (FIG_BACK[ch] ?? "?") : ch;
    }
    return out;
  }
  function makeMessage(r, length = 5000) {
    const de = [], en = [];
    let tele = "";
    while (tele.length < length) {
      const [g, e] = PICK(r, SENTENCES)(r);
      de.push(g); en.push(e);
      tele += teleprinter((de.length % 4 === 0 ? "\n" : de.length > 1 ? " " : "") + g, r);
    }
    return { tele: tele.slice(0, length), german: de.join(" "), english: en.join(" ") };
  }

  // ---- what Bletchley knew about the language -------------------------------------------------
  // P(dot) of dP_i + dP_k for each impulse pair, measured on a long sample of the same kind of traffic
  // (the cryptanalysts kept such statistics). Index "i,k" with i < k, impulses 0-based.
  const LANG = (() => {
    const r = rng(1944), P = toCodes(makeMessage(r, 60000).tele), out = {};
    for (let i = 0; i < 5; i++) for (let k = i + 1; k < 5; k++) {
      let dots = 0;
      for (let t = 0; t + 1 < P.length; t++) if (!((((P[t] ^ P[t + 1]) >> i) ^ ((P[t] ^ P[t + 1]) >> k)) & 1)) dots++;
      out[`${i},${k}`] = dots / (P.length - 1);
    }
    return out;
  })();

  // ---- Colossus ----------------------------------------------------------------------------------
  // dZ for impulse pair (i, k): the delta of the cipher tape, impulses i and k added.
  function deltaPair(Z, i, k) { const n = Z.length - 1, out = new Uint8Array(n); for (let t = 0; t < n; t++) { const d = Z[t] ^ Z[t + 1]; out[t] = ((d >> i) ^ (d >> k)) & 1; } return out; }
  const deltaWheel = (key, k) => { const L = SIZES.chi[k], p = key.chi[k]; return Uint8Array.from({ length: L }, (_, j) => p[j] ^ p[(j + 1) % L]); };
  // Count, over the tape, how often dZ_ik + dchi_i + dchi_k is a dot (or a cross) for chi starts si, sk.
  function count(dz, dA, sA, dB, sB, dots) {
    const LA = dA.length, LB = dB.length; let c = 0, a = sA % LA, b = sB % LB;
    for (let t = 0; t < dz.length; t++) { if ((dz[t] ^ dA[a] ^ dB[b]) === (dots ? 0 : 1)) c++; if (++a === LA) a = 0; if (++b === LB) b = 0; }
    return c;
  }
  // Tutte's 1+2 break-in: all 41 x 31 starting pairs; counts[s1 * 31 + s2].
  function run12(Z, key) {
    const dz = deltaPair(Z, 0, 1), d1 = deltaWheel(key, 0), d2 = deltaWheel(key, 1), counts = new Int32Array(41 * 31);
    for (let s1 = 0; s1 < 41; s1++) for (let s2 = 0; s2 < 31; s2++) counts[s1 * 31 + s2] = count(dz, d1, s1, d2, s2, true);
    return { counts, n: dz.length };
  }
  // The next short run: the unset chi wheel whose known language biases with the already-set wheels are
  // strongest; it is counted against its two best set partners, each counting dots or crosses to match
  // its bias (a simplified version of the Newmanry's run choices). Counts from the two pairs are added.
  function nextShortRun(found) {
    const set = Object.keys(found).map(Number);
    let best = null;
    for (let k = 0; k < 5; k++) {
      if (k in found) continue;
      const pairs = set.map((i) => { const b = LANG[i < k ? `${i},${k}` : `${k},${i}`]; return { partner: i, dots: b > .5, m: Math.abs(b - .5) }; })
        .sort((a, b) => b.m - a.m).slice(0, 2);
      const strength = pairs.reduce((a, p) => a + p.m, 0);
      if (!best || strength > best.strength) best = { wheel: k, pairs, strength };
    }
    return best && { wheel: best.wheel, pairs: best.pairs.map(({ partner, dots }) => ({ partner, dots })) };
  }
  function shortRun(Z, key, found, plan) {
    const dk = deltaWheel(key, plan.wheel), counts = new Int32Array(SIZES.chi[plan.wheel]);
    let n = 0;
    for (const { partner, dots } of plan.pairs) {
      const dz = deltaPair(Z, Math.min(plan.wheel, partner), Math.max(plan.wheel, partner)), dp = deltaWheel(key, partner);
      for (let s = 0; s < counts.length; s++) counts[s] += count(dz, dp, found[partner], dk, s, dots);
      n += dz.length;
    }
    return { counts, n };
  }
  const sigma = (n) => Math.sqrt(n) / 2;                      // binomial spread of a count at p = 1/2
  const setTotal = (n, sigmas = 2.5) => Math.ceil(n / 2 + sigmas * sigma(n));
  const sigmasOf = (count, n) => (count - n / 2) / sigma(n);
  // A typewriter line: wheel positions numbered from 01 as at Bletchley, then the count.
  const typedLine = (positions, count) => positions.map((p) => String(p + 1).padStart(2, "0")).join(" ") + "  " + String(count).padStart(5);

  // ---- after Colossus ----------------------------------------------------------------------------
  // De-chi: remove the chi stream found by Colossus; what remains is P + psi'.
  function dechi(Z, key, chiStart) { const ks = keystream(key, { chi: chiStart, psi: [0, 0, 0, 0, 0], mu: [0, 0] }, Z.length); return Z.map((v, i) => v ^ ks.chi[i]); }
  // The Testery's result: remove psi' with the psi and motor settings (found by hand at Bletchley;
  // applied here from the puzzle, as the page explains).
  function testery(D, key, start) { const ks = keystream(key, start, D.length); return D.map((v, i) => v ^ ks.psi[i]); }

  function makePuzzle(seed, length = 5000) {
    const r = rng(seed), key = makeKey(r), start = randomStart(r), message = makeMessage(r, length);
    const P = toCodes(message.tele), Z = encipher(P, key, start);
    return { seed, key, start, message, P, Z };
  }

  return { SIZES, rng, CODE, CHAR, toCodes, toText, dotCross, makeKey, randomStart, keystream, encipher, teleprinter, readable, makeMessage, LANG,
    deltaPair, deltaWheel, run12, nextShortRun, shortRun, sigma, setTotal, sigmasOf, typedLine, dechi, testery, makePuzzle };
})();
```

```js
// ---- the electric typewriter: types queued result lines onto the paper, a character at a time ------
const typewriter = {
  queue: [], lines: [], cur: "", target: null, acc: 0, rows: [],
  type(line) { this.queue.push(line); },
  clear() { this.queue = []; this.lines = []; this.cur = ""; this.target = null; this.acc = 0; this.render(); },
  busy() { return !!this.target || this.queue.length > 0; },
  // rate in characters per second. A long backlog (a low set total at high speed) goes straight onto
  // the paper, keeping the last 40 lines to type, and a short backlog is typed faster than `rate`, so the
  // paper never falls minutes behind the machine.
  update(dt, rate) {
    if (this.queue.length > 40) {
      if (this.target) { this.lines.push(this.target); this.target = null; this.cur = ""; }
      this.lines.push(...this.queue.splice(0, this.queue.length - 40));
      if (this.lines.length > 400) this.lines.splice(0, this.lines.length - 400);
      sound.carriageReturn();
    }
    const backlog = this.queue.reduce((a, l) => a + l.length + 1, 0) + (this.target ? this.target.length - this.cur.length + 1 : 0);
    if (!backlog) return;
    this.acc += dt * Math.max(rate, this.queue.length > 3 ? backlog / 2 + 40 : 0);
    while (this.acc >= 1) {
      this.acc -= 1;
      if (!this.target) { if (!this.queue.length) { this.acc = 0; break; } this.target = this.queue.shift(); this.cur = ""; }
      if (this.cur.length < this.target.length) { const ch = this.target[this.cur.length]; this.cur += ch; if (ch !== " ") sound.key(); }
      else { this.lines.push(this.cur); if (this.lines.length > 400) this.lines.splice(0, this.lines.length - 400); this.target = null; this.cur = ""; sound.carriageReturn(); }
    }
    this.render();
  },
  render() {
    const ROWS = 34, LINE = 13.6, bottom = 498;
    if (!this.rows.length) for (let i = 0; i < ROWS; i++) { const t = document.createElementNS(SVGNS, "text"); t.setAttribute("x", 1426); machine.paper.appendChild(t); this.rows.push(t); }
    const all = this.target ? [...this.lines, this.cur] : this.lines, shown = all.slice(-ROWS);
    this.rows.forEach((t, i) => { const line = shown[shown.length - 1 - i]; t.textContent = line ?? ""; t.setAttribute("y", (bottom - i * LINE).toFixed(1)); });
  }
};
```

```js
  if (!S.demo || S.threading >= 0 || (S.run && S.run.running) || typewriter.busy()) return;
  if ((S.demoWait -= dt) > 0) return;
  S.demoWait = 1.2;
  const N = S.pz.Z.length;
  switch (S.step) {
    case 0: if (S.reached === 0) thread(); else go(1); break;
    case 1: {
      const r = S.r12;
      if (r && r.done && r.printed.length) go(2);
      else if (r && !r.done) { S.run = r; resumeRun(); }
      else { $("total").value = Colossus.setTotal(N - 1); startRun("12"); }
      break;
    }
    case 2: if (S.r12 && S.r12.printed.length) pick12(topOf(S.r12)); else go(1); break;
    case 3: {
      const run = S.run && S.run.kind === "short" ? S.run : null;
      if (!Colossus.nextShortRun(S.found)) go(4);
      else if (run && run.done && run.printed.length) pickShort(topOf(run));
      else if (run && !run.done) resumeRun();
      else { $("total").value = Colossus.setTotal(2 * (N - 1), 1); startRun("short"); }
      break;
    }
    case 4: go(5); break;
    default: setDemo(false); toast("Demo finished");
  }
}

  machine.activity += ((S.run && S.run.running ? 1 : .3) - machine.activity) * Math.min(1, dt * 3);

}
```

- [ ] **Step 1: Write the engine**

```js
// ---- sound: synthesized, off until the first Start ------------------------------------------------
// Beds that follow the machine (tape, motor, pulleys, valve room) plus one-shots (relays, typewriter,
// splice). Accelerated speeds make passes come faster; the tape itself always sounds at real speed.
const sound = {
  ctx: null, out: null, analyser: null, noise: null, on: false, volume: .7, bed: null, last: {},
  ensure() {
    if (this.ctx) return;
    const ctx = this.ctx = new (window.AudioContext || window.webkitAudioContext)();
    const comp = ctx.createDynamicsCompressor(); comp.threshold.value = -16; comp.ratio.value = 4;
    this.out = ctx.createGain(); this.out.gain.value = 0;
    this.analyser = ctx.createAnalyser(); this.analyser.fftSize = 2048;
    this.out.connect(comp); comp.connect(ctx.destination); comp.connect(this.analyser);
    const buf = this.noise = ctx.createBuffer(1, ctx.sampleRate * 2, ctx.sampleRate), d = buf.getChannelData(0), r = Colossus.rng(1944);
    for (let i = 0; i < d.length; i++) d[i] = r() * 2 - 1;
    const gain = (v, to = this.out) => { const g = ctx.createGain(); g.gain.value = v; g.connect(to); return g; };
    const filt = (type, f, q, to) => { const b = ctx.createBiquadFilter(); b.type = type; b.frequency.value = f; b.Q.value = q; b.connect(to); return b; };
    const noise = (to) => { const s = ctx.createBufferSource(); s.buffer = buf; s.loop = true; s.connect(to); s.start(0, Math.random() * 2); return s; };
    const osc = (type, f, to) => { const o = ctx.createOscillator(); o.type = type; o.frequency.value = f; o.connect(to); o.start(); return o; };
    const bed = this.bed = {};
    // tape: paper rushing past the reader and over the pulleys, fluttering once a lap
    bed.tape = gain(0); noise(filt("bandpass", 2400, .7, bed.tape));
    bed.hiss = gain(0); noise(filt("highpass", 6500, .5, bed.hiss));
    bed.flutter = gain(0, bed.tape.gain); bed.lap = osc("sine", 1, bed.flutter);       // the level wobbles once a lap
    bed.sprocket = gain(0); bed.sprocketOsc = osc("sine", 5000, bed.sprocket);        // 5,000 holes a second sing faintly
    bed.pulley = gain(0); bed.pulleyOsc = osc("triangle", 160, filt("lowpass", 900, .7, bed.pulley));
    // motor
    bed.motor = gain(0); bed.motorOsc = osc("sawtooth", 100, filt("lowpass", 380, 1, bed.motor));
    // the valve room: fans, 50 Hz mains hum, a faint buzz that rises while counting
    noise(filt("lowpass", 650, .5, gain(.045)));
    osc("sine", 50, gain(.03)); osc("sine", 150, gain(.01));
    bed.buzz = gain(.004); osc("sawtooth", 50, filt("bandpass", 1100, 2, bed.buzz));
  },
  setEnabled(on) {
    this.on = on;
    if (on) { this.ensure(); this.ctx.resume(); }
    if (this.ctx) this.out.gain.setTargetAtTime(on ? this.volume : 0, this.ctx.currentTime, .08);
  },
  setVolume(v) { this.volume = v; if (this.ctx && this.on) this.out.gain.setTargetAtTime(v, this.ctx.currentTime, .05); },
  update() {
    if (!this.ctx || !this.on) return;
    const t = this.ctx.currentTime, v = machine.shown, b = this.bed, set = (p, x) => p.setTargetAtTime(x, t, .06);
    set(b.tape.gain, .1 * v); set(b.flutter.gain, .03 * v); set(b.lap.frequency, Math.max(.01, v));
    set(b.hiss.gain, .035 * v);
    set(b.sprocket.gain, .0035 * v); set(b.sprocketOsc.frequency, 40 + 4960 * v);
    set(b.pulley.gain, .02 * v); set(b.pulleyOsc.frequency, 40 + 120 * v);
    set(b.motor.gain, .07 * Math.min(1, v * 1.5)); set(b.motorOsc.frequency, 60 + 40 * v);
    set(b.buzz.gain, .004 + .012 * machine.activity);
  },
  // a short filtered noise burst, and a decaying tone
  burst(t, dur, f, q, g, type = "bandpass") {
    const ctx = this.ctx, s = ctx.createBufferSource(), fl = ctx.createBiquadFilter(), e = ctx.createGain();
    s.buffer = this.noise; fl.type = type; fl.frequency.value = f; fl.Q.value = q;
    e.gain.setValueAtTime(g, t); e.gain.exponentialRampToValueAtTime(.0001, t + dur);
    s.connect(fl); fl.connect(e); e.connect(this.out); s.start(t, Math.random() * 1.5); s.stop(t + dur + .02);
  },
  tone(t, dur, f, g, type = "sine") {
    const ctx = this.ctx, o = ctx.createOscillator(), e = ctx.createGain();
    o.type = type; o.frequency.value = f; e.gain.setValueAtTime(g, t); e.gain.exponentialRampToValueAtTime(.0001, t + dur);
    o.connect(e); e.connect(this.out); o.start(t); o.stop(t + dur + .02);
  },
  ready(name, gap) { if (!this.on || !this.ctx) return false; const t = this.ctx.currentTime; if (t - (this.last[name] ?? -1) < gap) return false; this.last[name] = t; return true; },
  // relays latching the counts at the end of a pass: a ragged little clatter, one click per counter and then some
  relays(n) {
    if (!this.ready("relays", .04)) return;
    const t = this.ctx.currentTime;
    for (let i = 0; i < Math.min(n, 5) + 2; i++) { const dt = Math.random() * .05; this.burst(t + dt, .006 + Math.random() * .006, 2400 + Math.random() * 2200, 2, .12 + Math.random() * .14); }
    this.tone(t, .03, 90, .08);
  },
  key() {
    if (!this.ready("key", .03)) return;
    const t = this.ctx.currentTime + Math.random() * .006;
    this.burst(t, .012, 1600 + Math.random() * 600, 1.2, .2 + Math.random() * .08);
    this.tone(t, .05, 130 + Math.random() * 25, .1);
  },
  carriageReturn() {
    if (!this.ready("cr", .08)) return;
    const t = this.ctx.currentTime;
    this.burst(t, .2, 900 + Math.random() * 300, .8, .06);
    this.tone(t + .18, .08, 70, .16); this.burst(t + .18, .015, 2200, 1.5, .1);
  },
  bell() { if (!this.ready("bell", .3)) return; const t = this.ctx.currentTime; this.tone(t, 1.4, 2093, .1); this.tone(t, .6, 5230, .03); },
  splice() { if (machine.shown > .3 && this.ready("splice", .2)) this.burst(this.ctx.currentTime, .004, 3500, 1, .1 * machine.shown, "highpass"); },
  level() {
    if (!this.analyser) return 0;
    const a = new Float32Array(this.analyser.fftSize); this.analyser.getFloatTimeDomainData(a);
    return Math.sqrt(a.reduce((s, x) => s + x * x, 0) / a.length);
  }
};
```
